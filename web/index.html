Install Logos on this Mac for me. Logos is an open-source macOS menu-bar dictation app (https://logosvoice.dev, source https://github.com/ninjudd/logos). You run the commands. Some steps only I can do; for those, stop, tell me exactly what to do, and wait until I say it's done.

Don't use sudo. Don't try to grant macOS permissions yourself: no tccutil, no editing TCC databases, no scripting clicks in System Settings. Don't ask me to paste API keys into this chat, and never print, copy, or commit ~/.config/logos/config.json.

1. Prerequisites. Run `sw_vers -productVersion`; Logos needs macOS 26 or later, so stop and tell me if it's older. Run `xcrun --find swift`. If that fails, ask me to run `xcode-select --install` and finish its installer window, then check again.
2. Install. Show me what the installer does first: fetch https://logosvoice.dev/install.sh and summarize it in two sentences. Then run `curl -fsSL https://logosvoice.dev/install.sh | bash`. It downloads the latest release's source from GitHub, builds it (a few minutes), installs /Applications/Logos.app, links the `logos` command into ~/.local/bin, and starts the app. If it fails, show me the error and stop.
3. Verify: /Applications/Logos.app exists, `pgrep -x Logos` finds it running, and `~/.local/bin/logos version` prints a version. If ~/.local/bin isn't on my PATH, tell me and offer to add it to my shell profile; only edit the profile if I agree.
4. Permissions (my step). Tell me: when Logos starts, macOS asks for microphone access; click Allow. Then turn on Logos in System Settings → Privacy & Security → Accessibility; you may open that pane for me with `open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"`. Until it's on, holding Option does nothing; Logos notices the change within a few seconds, with no restart.
5. API keys (my step). Explain: transcription starts on Apple's on-device model, which needs no key; cleanup uses an Anthropic model and needs an Anthropic API key. Without one, Logos still pastes the raw transcript and shows "Cleanup failed, pasted raw text: No anthropic key…". For faster, more accurate transcription, Groq's free tier works well. Tell me to create the keys I want at console.anthropic.com and console.groq.com and paste them into Logos myself: click the waveform icon in the menu bar → Settings… → Config → API keys, and choose `groq/whisper-large-v3-turbo` from the Model menu under Transcription if I added a Groq key. Don't handle the keys yourself.
6. Test without the microphone: `say -o /tmp/logos-test.wav --data-format=LEI16@16000 "Um, testing Logos dictation"`, then `~/.local/bin/logos transcribe /tmp/logos-test.wav`. It prints the sentence on a `raw:` line and the cleaned-up text on a `clean:` line. Without an Anthropic key it prints that same "Cleanup failed" warning, which is expected if I skipped that key. Any other warning or error usually means a key is wrong; go back to step 5. Then ask me to click into any text field, hold Option, say a sentence, and let go. If the text appears there, we're done. If holding Option does nothing, Accessibility is still off.
7. Finish with one short message: what was installed and where, that settings live in ~/.config/logos/ and in Settings… from the menu-bar icon, that `logos update` updates it, and anything I still need to do.

Needs macOS 26 or later and Apple's free Command Line Tools (xcode-select --install). Logos builds from source on your Mac, so you need no developer account. The source is on GitHub.

Why Logos

Your prompt

The cleanup prompt is a file you edit. Logos rereads it on every dictation, and it can adapt to the app you're dictating into.

Your models

Pick each model with one line, such as anthropic/claude-haiku-5-5 or groq/whisper-large-v3-turbo. OpenAI, Groq, OpenRouter, and Ollama work too.

No server

Logos calls each provider straight from your Mac with your own API keys. Speech runs on the device by default, with no key at all.

Nothing lost

Dictate with no text field focused, and Logos shows the text in a card to copy instead of pasting it into nothing.

Set it up

After installing, a waveform icon appears in the menu bar. Allow Microphone and Accessibility access when macOS asks, then put your keys in ~/.config/logos/config.json:

{
  "transcription": { "model": "apple" },
  "cleanup": { "model": "anthropic/claude-opus-5-5", "effort": "low" },
  "keys": { "anthropic": "sk-ant-..." }
}

The logos command runs an audio file through the same pipeline, so you can try a prompt change without dictating, and logos update builds and installs the newest release.

Logos is open source under the MIT License, at github.com/ninjudd/logos. It's built from source on each Mac, and it sends your audio and text only to the providers you configure.
